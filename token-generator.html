📋 How to Use

1. Make sure your backend is running: cd backend && npm start

2. Your backend already validates authentication - no extra Firebase auth needed!

3. Fill in your User ID, Event ID, and Auth Token below

4. Click "Generate Token" - Firebase will trust this custom token automatically

5. Use the token in Firebase Chat Test UI (no additional authentication required!)
