# 🔥 CURL COMMANDS: FIRST TIME MESSAGES & ONGOING MESSAGES - CommAPP API

## 📋 **PREREQUISITE: Authentication**
```bash
# Step 1: Login to get token
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "user@example.com", "password": "password123"}'

# Extract token from response
TOKEN="your-jwt-token-from-login-response"
```

---

## 🎯 **STEP 1: GET FIREBASE ROOM ID (REQUIRED FOR ALL MESSAGES)**
```bash
# Get Firebase room ID from event
ROOM_ID=$(curl -s -X GET http://localhost:5000/api/events/EVENT_ID_HERE/chat/room \
  -H "Authorization: Bearer $TOKEN" | grep -o '"chatRoomId":"[^"]*' | cut -d'"' -f4)

echo "Firebase Room ID: $ROOM_ID"
```

## 🔄 **COMPLETE WORKFLOW AUTOMATION**

### **First Time Message Workflow:**
```bash
#!/bin/bash

# Configuration
EVENT_ID="YOUR_EVENT_ID"
TOKEN="YOUR_JWT_TOKEN"
YOUR_NAME="Your Name"

echo "🎯 Starting first-time message workflow..."

# Get Firebase Room ID
ROOM_ID=$(curl -s -X GET http://localhost:5000/api/events/$EVENT_ID/chat/room \
  -H "Authorization: Bearer $TOKEN" | grep -o '"chatRoomId":"[^"]*' | cut -d'"' -f4)

echo "📱 Room ID: $ROOM_ID"

# Send welcome message
echo "💬 Sending welcome message..."
curl -s -X POST http://localhost:5000/api/chat/rooms/$ROOM_ID/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d "{\"content\": \"Hello everyone! I'm $YOUR_NAME. Excited to be part of this event! 👋\", \"messageType\": \"text\"}"

# Send introduction
echo "👤 Sending introduction..."
curl -s -X POST http://localhost:5000/api/chat/rooms/$ROOM_ID/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d "{\"content\": \"This is my first time here and I'm looking forward to learning from everyone!\", \"messageType\": \"text\"}"

# Ask engagement question
echo "❓ Asking engagement question..."
curl -s -X POST http://localhost:5000/api/chat/rooms/$ROOM_ID/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d "{\"content\": \"What should I expect from today's session? Any tips for newcomers? 🤔\", \"messageType\": \"text\"}"

echo "✅ First-time messages sent successfully!"
```

### **Ongoing Message Workflow:**
```bash
#!/bin/bash

# Configuration
ROOM_ID="room_1765521236401_hbyfwtdbw"
TOKEN="YOUR_JWT_TOKEN"

echo "🔄 Starting ongoing conversation workflow..."

# Send follow-up message
echo "💬 Sending follow-up..."
curl -s -X POST http://localhost:5000/api/chat/rooms/$ROOM_ID/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"content": "Thanks for the great explanation! I have one more question about the implementation...", "messageType": "text"}'

# Send reaction to previous message
echo "👍 Adding reaction..."
curl -s -X POST http://localhost:5000/api/chat/messages/msg_1765521236401_previous_message_id/reactions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"emoji": "👍", "roomId": "'$ROOM_ID'"}'

# Share additional resource
echo "📚 Sharing resource..."
curl -s -X POST http://localhost:5000/api/chat/rooms/$ROOM_ID/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"content": "Here\'s an additional resource that might help with the topic we discussed", "messageType": "file"}'

echo "✅ Ongoing messages sent successfully!"
```
