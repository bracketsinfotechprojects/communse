## 🚀 **RECOMMENDED WORKFLOW: Get Firebase Room ID from Event**

### Step 1: Get Firebase Room ID from Event Document
```bash
curl -X GET http://localhost:5000/api/events/EVENT_ID_HERE/chat/room \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE" \
  -H "Content-Type: application/json"
```

**Response Example:**
```json
{
  "success": true,
  "data": {
    "eventId": "507f1f77bcf86cd799439011",
    "chatRoomId": "room_1765521236401_hbyfwtdbw",
    "chatRoomCreated": true,
    "eventTitle": "Tech Meetup 2025"
  }
}
```

### Step 2: Extract Firebase Room ID and Send Message
```bash
# Extract room ID from response and send message
ROOM_ID=$(curl -s -X GET http://localhost:5000/api/events/EVENT_ID_HERE/chat/room \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE" | grep -o '"chatRoomId":"[^"]*' | cut -d'"' -f4)

curl -X POST http://localhost:5000/api/chat/rooms/$ROOM_ID/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE" \
  -d '{
    "content": "Hello everyone! Looking forward to this event!",
    "messageType": "text"
  }'
```

## 🔄 **COMPLETE AUTOMATED WORKFLOW**

### Automated Event Message Script
```bash
#!/bin/bash

# Configuration - Replace with your values
EVENT_ID="507f1f77bcf86cd799439011"
TOKEN="your-jwt-token-here"
MESSAGE="Hello from the automated script!"

echo "🔍 Getting Firebase Room ID for event: $EVENT_ID"

# Get room info and extract Firebase room ID
ROOM_INFO=$(curl -s -X GET http://localhost:5000/api/events/$EVENT_ID/chat/room \
  -H "Authorization: Bearer $TOKEN")

ROOM_ID=$(echo $ROOM_INFO | grep -o '"chatRoomId":"[^"]*' | cut -d'"' -f4)

if [ -z "$ROOM_ID" ]; then
    echo "❌ Failed to get room ID"
    exit 1
fi

echo "📱 Firebase Room ID: $ROOM_ID"

echo "💬 Sending message..."
SEND_RESPONSE=$(curl -s -X POST http://localhost:5000/api/chat/rooms/$ROOM_ID/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d "{\"content\": \"$MESSAGE\", \"messageType\": \"text\"}")

echo "📤 Message Response:"
echo "$SEND_RESPONSE" | jq '.'

echo "📋 Getting latest messages..."
curl -s -X GET "http://localhost:5000/api/chat/rooms/$ROOM_ID/messages?limit=5" \
  -H "Authorization: Bearer $TOKEN" | jq '.'

echo "✅ Workflow completed!"
```

## ⚠️ **IMPORTANT NOTES**

### Firebase Room ID Format:
- Format: `room_TIMESTAMP_RANDOMSTRING`
- Example: `room_1765521236401_hbyfwtdbw`
- Generated by Firebase service automatically

### Authentication:
- All endpoints require valid JWT token
- Token expires after configured time

### Message Types:
- `text` - Regular text messages (default)
- `image` - Image attachments
- `file` - Document attachments
- `audio` - Voice messages
- `video` - Video attachments

### Limits:
- Maximum 2000 characters per message content
- Maximum 1000 participants per room

### Permissions:
- Only event attendees can send messages in event chat
- Only message sender can edit/delete their messages
- Room participants can view messages and add reactions

## 🔧 **TROUBLESHOOTING**

### Common Issues:

1. **401 Unauthorized:** Check if your JWT token is valid and not expired
2. **403 Forbidden:** Ensure you have permission to send messages in that chat room
3. **404 Not Found:** Verify the event ID and Firebase room ID exist
4. **400 Bad Request:** Check message content length (max 2000 chars) and required fields

### Debug Commands:
```bash
# Check backend status
```
