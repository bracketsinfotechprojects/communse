## 🚨 **IF YOU STILL GET ERRORS**

### **Error: "Event not found"**
- Your event ID might be wrong
- You might not be attending that event

### **Error: "Access denied"**
- You need to join the event first
- Only event attendees can send messages

### **Error: "Chat room not found"**
- The event doesn't have a chat room created
- Try publishing the event first

## 🎯 **SIMPLEST WORKING EXAMPLE**

### **Complete Working Flow:**
```bash
#!/bin/bash

TOKEN="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOiI2OTM3Y2E4YTYyN2YxNTIzODRhYzE4ODQiLCJpYXQiOjE3NjU1MjAwNjAsImV4cCI6MTc2ODExMjA2MH0.r2Mi4RT94DA-JtSjF8Q0zI2qyhpMdZSjQ3hulC7vdOw"

echo "🔍 Step 1: Getting your events..."
EVENTS=$(curl -s -X GET http://localhost:5000/api/chat/users/events \
  -H "Authorization: Bearer $TOKEN)

echo "📋 Your events:"
echo "$EVENTS" | jq '.'

# Extract first event ID
EVENT_ID=$(echo "$EVENTS" | jq -r '.[0].eventId // empty')

if [ -z "$EVENT_ID" ] || [ "$EVENT_ID" = "null" ]; then
    echo "❌ No events found. You need to join or create an event first."
    exit 1
fi

echo "🎯 Using event ID: $EVENT_ID"

echo "💬 Step 2: Sending test message..."
RESULT=$(curl -s -X POST http://localhost:5000/api/events/$EVENT_ID/chat/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"content": "Hello from debugging script!", "messageType": "text"}')

echo "📤 Response:"
echo "$RESULT" | jq '.'

if echo "$RESULT" | jq -e '.success' > /dev/null; then
    echo "✅ SUCCESS! Message sent!"
else
    echo "❌ FAILED! Check the error above."
fi
```
