# Event Creation cURL Examples

## Prerequisites:
1. First, get an authentication token by logging in:
```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "your-email@example.com", "password": "your-password"}'
```

2. Extract the token from the response and use it in the event creation request.

## Event Creation cURL Commands:

### 1. Create a Basic Event:
```bash
curl -X POST http://localhost:5000/api/events \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE" \
  -d '{
    "title": "Tech Meetup 2025",
    "description": "Join us for an exciting tech meetup where we'll discuss the latest trends in web development, AI, and blockchain technology.",
    "communityId": "COMMUNITY_ID_HERE",
    "startTime": "2025-12-15T14:00:00.000Z",
    "endTime": "2025-12-15T18:00:00.000Z",
    "location": {
      "city": "Mumbai",
      "landmark": "Tech Park",
      "coordinates": {
        "latitude": 19.0760,
        "longitude": 72.8777
      },
      "fullAddress": "Tech Park, Bandra Kurla Complex, Mumbai, Maharashtra 400051"
    },
    "category": "networking",
    "maxAttendees": 50,
    "isPublic": true,
    "tags": ["technology", "networking", "web-development"],
    "coverImage": "https://example.com/event-cover.jpg",
    "requirements": "Laptop required for hands-on session",
    "contactInfo": "contact@techmeetup.com"
  }'
```

## Next Steps After Event Creation:

### 1. Publish the Event:
```bash
curl -X POST http://localhost:5000/api/events/EVENT_ID_HERE/publish \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE"
```

### 2. Join the Event:
```bash
curl -X POST http://localhost:5000/api/events/EVENT_ID_HERE/join \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE"
```

### 3. Get Event Chat Info:
```bash
curl -X GET http://localhost:5000/api/events/EVENT_ID_HERE/chat \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE"
```

### 4. Send Message in Event Chat:
```bash
curl -X POST http://localhost:5000/api/events/EVENT_ID_HERE/chat/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE" \
  -d '{
    "content": "Looking forward to this event!",
    "messageType": "text"
  }'
```

## Notes:
- Replace `YOUR_JWT_TOKEN_HERE` with the actual JWT token from login
- Replace `COMMUNITY_ID_HERE` with a valid community ID
- Replace `EVENT_ID_HERE` with the actual event ID after creation
- All events are created in "draft" status and need to be published manually
- Event chat rooms are automatically created when events are published
- Only community members can create events for that community
